Research note

Model: implied value = TVL x sizeMultiple(TVL) x 0.75 x growthMult x maturityMult. sizeMultiple is fitted at run time from the snapshot's own live tokens: log10(multiple) = 3.02 - 0.48 x log10(TVL), n = 128, corr -0.41, clamped to [0.02, 0.80].

Backtest: 5-fold cross-validation on the 128 live tokens gives median |log10 error| 0.56 (3.6x), against 0.72 (5.3x) for a flat median multiple. A category multiple adds nothing once size is in, so the model has no category term.

Conviction (0–100) = scale 25 + momentum 20 + maturity 20 + peers 20 + agreement 15. Scale measures TVL size against the board's log-TVL range; momentum measures 7-day TVL change (null scores a neutral 10); maturity measures age up to 3 years; peers measures how many live tokens share the row's category (0 peers scores 0, 1–2 scores 7, 3–5 scores 13, 6+ scores 20); agreement measures how close the row's fitted multiple sits to its category's live median (within 0.10 dex scores 15, 0.25 scores 11, 0.40 scores 7, further scores 3, no peers scores 8). Conviction never changes the implied value or the rank; on this board it runs 15–74 with median 40.5.

Category medians are context, not a multiplier: each is the median mcap/TVL of the live tokens in that category (33 categories; 18 board rows sit in categories with no live peers, so they have no median). The v2 backtest found a category term adds nothing out-of-sample — the size curve alone scored 0.55 and adding a category shift scored 0.56 — so no category term enters the value formula. Treat thin medians with care: Risk Curators' median 2.97 rests on a single live peer. The Categories tab lists all 33 categories with board rows, live peers and median multiple.

Pre-token haircut: 0.75. Exclusions: 144 pre-token protocols are off the board because they are wrapped, bridged, staked or exchange products of tokens that already trade, not protocols awaiting a token launch.

Limits: the snapshot is frozen 2026-11-14. Multiples are comparables, not predictions, and no protocol name is hardcoded into the model.
